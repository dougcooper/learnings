## TLS 1.3 — RFC 8446

Two self-contained walkthroughs of [RFC 8446](https://datatracker.ietf.org/doc/html/rfc8446):
the 1-RTT handshake, the key schedule, the record layer, 0-RTT resumption,
the TLS 1.2 features that were removed and why, and downgrade protection.
